# Repository Intelligence Engine

Handles ingestion, parsing, and structural analysis of TEAL/PyTeal codebases.

## Modules

### ingestion/
- ZIP extraction
- File validation
- Repository structure detection

### parsers/
- TEAL parser
- PyTeal parser
- AST generation

### file-system/
- File tree traversal
- File type detection
- Path normalization

### dependency-graph/
- Import/dependency resolution
- Module relationships
- Circular dependency detection

### contract-graph/
- Contract identification
- Function extraction
- Storage operation mapping
