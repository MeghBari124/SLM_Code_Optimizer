# Test Fixtures

Sample TEAL/PyTeal contracts for testing the analysis engine.

## Directory Structure

- `teal/` - Sample TEAL contracts
- `pyteal/` - Sample PyTeal contracts
- `repositories/` - Full repository examples

## Fixture Categories

### Good Examples
- Well-optimized contracts
- Best practices
- Baseline for comparison

### Bad Examples
- Unoptimized patterns
- Known anti-patterns
- Security issues
- Cost inefficiencies

### Edge Cases
- Complex control flow
- Edge conditions
- Boundary testing

## Adding Fixtures

1. Add contract file with descriptive name
2. Include comment header explaining the pattern
3. Add expected findings in adjacent `.expected.json` file
